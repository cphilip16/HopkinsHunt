# Repository Agent Instructions

## Collaboration and Git Workflow

- Never push changes directly to `main` while working on a project change.
- Create a separate branch for every change.
- Keep each branch focused on one task and use a descriptive name, such as `feature/<short-description>` or `fix/<short-description>`.
- Commit related changes to the branch and push the branch to the remote.
- Merge changes into `main` only through a pull request.
- Pull requests should be reviewed by another contributor before merging.
- Do not rewrite or discard another contributor's work. Resolve conflicts carefully and preserve the intent of both changes.
